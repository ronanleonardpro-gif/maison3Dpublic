# Maison 3D

Maquette 3D interactive d'une maison et de son voisinage : vues intérieures en coupe, cotes, mesures, ensoleillement, ombres au fil de l'année et aménagement avec des objets aux dimensions réelles.

Ouvrir la page : https://ronanleonardpro-gif.github.io/maison3Dpublic/

Ce dépôt ne contient que la page publiée (`index.html`, fichier autonome). Le code source et la documentation sont tenus dans un dépôt séparé.
